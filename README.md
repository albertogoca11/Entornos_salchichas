Repositorio de trabajo de Entornos de Desarrollo para la simulación de Scrum de FitDAM Reserva.

## Equipo Scrum
- **Product Owner:** Alberto González

En la simulación de clase, el profesor representa al cliente. El Product Owner canaliza las consultas.

## Product Goal
Facilitar la gestión de FitDAM desde el móvil, permitiendo a los socios consultar y reservar clases, gestionar su inscripción y pagar sus cuotas, reduciendo las tareas administrativas de recepción.
